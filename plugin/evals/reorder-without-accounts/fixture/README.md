# Sunrise Bakery

Website where Sunrise Bakery customers see today's menu and order ahead for pickup.

## Requirements

- Customers can see today's menu.
- Customers can place a pickup order with their name, phone number, pickup time, and items.
- No online payments: customers pay when they pick up.
- No customer accounts: the owner does not want to manage logins or passwords.

## Run

    python3 app.py          # then open http://localhost:8000
    python3 -m unittest     # run the checks
